# 冉书寒

这是独立于 `layout-editor/` 的零依赖静态个人简历网站。

## 启动

双击 `启动网站.bat`，或在本目录运行：

```powershell
node server.mjs
```

浏览器访问 `http://127.0.0.1:4174`。

## 当前交互

- 顶部 `RAN SHUHAN` 导航栏保持独立；其下内容区使用全幅春日花草背景，不再绘制网格。桌面端鼠标显示为会随移动方向旋转的棒棒糖，移动时在花草上留下春日配色的透明涟漪和小水滴，点击会产生更明显的三层扩散波。
- 首页使用 `assets/` 中的粉色裙装蜡笔人物 IP，并换用同画风的春日蜡笔花园背景。
- 靠近或键盘聚焦四个入口时，人物分别切换为读书、电脑、挥手和蛋糕成果状态；减弱动效时保留状态变化但取消弹跳动画。
- 首页采用清晰的网页式双栏结构：左侧为姓名与人物 IP，右侧为统一尺寸的 2×2 大入口卡片；移动端自动改为纵向布局。
- 四个入口使用一套统一的透明软陶 3D 图标，只保留英文分区名和中文标题，不再显示标题下方的说明小字。
- “简历与教育”包含研究生与本科主修课程、本科 GPA 与校级荣誉；打开面板时只加载简历图片预览，观看者点击独立按钮后才下载原始 PDF。
- “实习轨迹”将小黑长卷完整缩放到一屏，并支持点击放大；三段经历分别标注数据类型，每家公司保留 3 条简洁量化成果。
- “项目与作品”合并项目经历与 12 个作品图集。
- 作品封面可点击放大。
- 支持 Escape 关闭、键盘焦点循环、系统低动效偏好和手动减弱动效。

棒棒糖花草涟漪参考 [ReactBits Splash Cursor](https://reactbits.dev/tools/background-studio?bg=splash-cursor) 的视觉体验，采用项目内零依赖 Canvas 2D 实现。开启“减弱动效”或使用触摸设备时自动关闭自定义指针与涟漪，保留原生操作方式。

## 部署与后续更新

### GitHub Pages

GitHub 仓库使用个人主页名称 `shuhanran.github.io`，公开地址为 `https://shuhanran.github.io/`。`.github/workflows/pages.yml` 会在 `main` 分支更新后自动把 `dist/` 发布到 GitHub Pages。

后续更新 GitHub Pages：修改并验证 `dist/` 后，把改动提交并推送到 `main`；GitHub Actions 会自动发布，网址保持不变。可在仓库的 **Actions** 页面查看部署状态。

### Sites 托管

网站使用 `dist/` 作为静态发布目录，托管项目配置保存在 `.openai/hosting.json`。这个文件中的 `project_id` 会在首次部署时写入，用来保证后续更新继续发布到同一个网址；不要删除或手动替换它。

后续更新流程：

1. 修改 `dist/index.html`、`dist/styles.css`、`dist/app.js` 或 `dist/assets/` 中的对应内容。
2. 运行 `node server.mjs`，在 `http://127.0.0.1:4174` 检查桌面端和手机端效果。
3. 在 Codex 中说明“把 `portfolio-site` 当前版本更新上线”。Codex 会复用 `.openai/hosting.json` 中的站点 ID，保存新版本并部署，正式网址保持不变。
4. 若新版本有问题，可根据托管平台保存的历史版本回退；本地 Git 历史也会保留每次部署的源文件快照。

网站已公开部署在 `https://ran-shuhan-portfolio.shuhanran1108.chatgpt.site`。手机号、邮箱、出生年月和所在地没有直接写入网页正文，但 `dist/assets/resume.pdf` 及其预览图包含个人联系方式；用户已于 2026-11-21 确认公开访问。若以后不希望继续公开这些信息，应先替换为脱敏版简历，再发布新版本。
